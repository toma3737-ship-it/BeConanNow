# BeConanNow — ربط Supabase (نسخة تأسيسية)

هذه الحزمة تضيف ربطًا أوليًا بقاعدة بيانات Supabase ولوحة إدارة عربية. لا تحتوي على عنوان مشروعك أو مفاتيحه.

## الملفات الجديدة
- `admin.html` و`admin.js`: تسجيل دخول المسؤول ونموذج إنشاء القضايا والمشتبهين والأدلة والتلميحات والحل.
- `supabase-config.js`: ضع فيه Supabase URL وPublishable key فقط.
- `supabase-setup.sql`: يضيف الحقول المطلوبة ودالة للتحقق من الإجابة وكشف التفسير بعد الإرسال، دون منح الواجهة قراءة مباشرة لجدول الحلول.
- `.gitignore`: يمنع تتبع `node_modules` مستقبلًا.

## خطوات الإعداد
1. خذ نسخة احتياطية من مشروعك الحالي.
2. انسخ ملفات الحزمة إلى مجلد المشروع، مع استبدال الملفات المطابقة عند الطلب. لا تحذف ملفات المشروع الأخرى.
3. في `supabase-config.js` ضع Supabase URL وPublishable key من مشروع **BeConanNow** فقط. لا تضع `service_role` أو أي مفتاح سري في هذا الملف.
4. في Supabase SQL Editor، راجع وشغّل `supabase-setup.sql` مرة واحدة.
5. افتح `admin.html` على موقعك بعد النشر، وسجّل الدخول بحسابك الذي أضفته إلى `public.admin_users`.
6. أنشئ قضية تجريبية بحالة «مسودة». القضايا المنشورة فقط تظهر للاعبين. يمكنك إنشاء قضية بحالة «منشورة» عند جهوزيتها.
7. اختبر إرسال إجابة من الصفحة الرئيسية. بعد تسليم الإجابة، تعيد قاعدة البيانات نتيجة المطابقة وتفسير الحل. الحل لا يُقرأ مباشرة من الواجهة العامة.
8. بعد الاختبار، نفّذ Commit وPush إلى GitHub Pages.

## تنبيهات
- احتفظ بملفي `package.json` و`package-lock.json`، ولا ترفع `node_modules`.
- يجب أن يكون حساب الإدارة مسجلًا في `public.admin_users`؛ مجرد إنشاء حساب Supabase لا يمنحه صلاحية الإدارة.
- هذه نسخة تأسيسية للعب الفردي. الجولات التنافسية متعددة اللاعبين تحتاج نظام جلسات وإجابات مؤقتة على الخادم قبل إطلاقها.
- النقاط وحفظ التقدم في هذه النسخة ليسا نظام ترتيب تنافسي موثّقًا على الخادم بعد.
- لا تضع أي مفتاح إداري أو كلمة مرور داخل ملفات HTML/JavaScript.
- الموقع يستخدم JavaScript modules عبر HTTPS؛ اختبره عبر GitHub Pages أو خادم محلي، وليس بفتح `index.html` بالنقر المزدوج إذا منع المتصفح استيراد الوحدات.

## ملاحظة حول القضايا التجريبية السابقة
تمت إزالة الحلول والقضايا الثابتة من `app.js` حتى لا تُنشر الإجابات السرية ضمن ملفات الموقع. ستظهر القضايا الجديدة التي تنشئها من لوحة الإدارة. إن أردت إبقاء القضايا التجريبية السابقة، يمكن نقلها إلى قاعدة البيانات بدل ترك حلولها مكشوفة في ملفات الواجهة.
