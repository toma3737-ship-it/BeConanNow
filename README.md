# BeConanNow — تحديث التصميم

هذه الحزمة مبنية على ملف ZIP الأصلي الذي أنشأناه للمشروع. تم الحفاظ على بنية الصفحة ومعرّفات عناصر JavaScript، مع تحديث الاسم والهوية البصرية إلى مزيج أنمي تحقيقي وسينمائي راقٍ.

## الملفات
- `index.html`: تحديث العلامة والنصوص التعريفية.
- `styles.css`: طبقة تصميم جديدة بألوان كحلية وسماوية ولمسات ذهبية خفيفة، تشمل الصفحة الرئيسية وبطاقات القضايا ونافذة التحقيق.
- `app.js`: منطق اللعب الأصلي محفوظ؛ التغيير الوحيد هو كتابة BCN على ختم بطاقات القضايا.

## طريقة التركيب
1. احتفظ بنسخة احتياطية من مجلد مشروعك الحالي.
2. فك ضغط الحزمة.
3. انسخ الملفات الأربعة من مجلد `investigation-platform` إلى مجلد مشروعك الحالي واستبدل الملفات عند الطلب.
4. افتح `index.html` واختبر البحث والتصفية وفتح القضايا والتلميحات وتثبيت الإجابة وكشف الحل وإغلاق النافذة.
5. إذا نجحت الاختبارات، نفّذ Commit ثم Push من VS Code لرفع التحديث إلى GitHub Pages.

ملاحظة: هذا تحديث واجهة أمامية فقط؛ لم يتم تغيير طريقة تخزين التقدم أو أمان الحلول. في النموذج الحالي يمكن الاطلاع على بيانات الحل من ملفات JavaScript، لذلك لا تعتمد عليه كمنصة مدفوعة قبل إضافة خادم وقاعدة بيانات بصلاحيات آمنة.


## ما الذي أُضيف في هذه النسخة؟
- عدسة مكبّرة مرئية ضمن مشهد الصفحة الرئيسية، مع عنصر بصري مكمل لعبارة كونان.
- استبدال العبارات العامة في الشريط بعبارات قصيرة مرتبطة بشعار كونان الشهير: «الحقيقة دائمًا واحدة!».
- إضافة مساحة بارزة للشعار الياباني وكتابته الصوتية.

## كيف تضيف قضية جديدة بنفسك؟
القضايا محفوظة حاليًا داخل مصفوفة اسمها `cases` في أعلى ملف `app.js`، ولا يوجد نظام إدارة قضايا على الموقع بعد. لإضافة قضية:
1. افتح `app.js` في VS Code.
2. ابحث عن `const cases = [`.
3. انزل إلى آخر قضية داخل المصفوفة، ثم أضف فاصلة بعد القوس `}` الخاص بها.
4. ألصق قالب القضية التالي قبل `];` النهائي، واملأ بياناته. يجب أن يكون `id` فريدًا، وأن تطابق أسماء الأشخاص في `accepted` اسم الخيار الصحيح تمامًا.
5. احفظ الملف، اختبر فتح القضية والتلميحات والإجابة والحل محليًا، ثم نفّذ Commit وPush.

## ملاحظة حول جودة القضايا
القضايا الحالية أمثلة تقنية لاختبار طريقة اللعب، وليست ألغازًا احترافية مكتملة. القضية الجيدة تحتاج أدلة قابلة للاستنتاج، وتناقضات منطقية، وحلًا تدعمه القرائن من دون أن يكون تخمينًا اعتباطيًا. يُفضّل مراجعة منطق كل قضية قبل نشرها للاعبين.
