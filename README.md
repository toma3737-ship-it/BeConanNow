# مَحضر — نموذج منصة التحقيقات العربية

نموذج واجهة متجاوبة للهاتف واللابتوب، مبني بـ HTML وCSS وJavaScript دون إطار عمل.

## تشغيله محليًا على Windows 11
1. فك ضغط الملف.
2. افتح مجلد `investigation-platform`.
3. انقر مرتين على `index.html` لفتحه في متصفح حديث.
4. يلزم اتصال بالإنترنت لتحميل خطي Google Fonts؛ ويمكن للموقع العمل بخط بديل عند عدم توفرهما.

## رفعه إلى GitHub Pages
1. أنشئ مستودعًا جديدًا في حساب GitHub.
2. ارفع الملفات الثلاثة: `index.html` و`styles.css` و`app.js`، ويمكنك رفع `README.md` أيضًا.
3. افتح إعدادات المستودع ثم **Pages**.
4. اختر النشر من الفرع `main` والمجلد `/ (root)` ثم احفظ.
5. انتظر حتى يظهر رابط الموقع في صفحة Pages، ثم افتحه على الهاتف واللابتوب.

## ما الذي يعمل في النموذج؟
- واجهة عربية RTL متجاوبة.
- مكتبة قضايا تجريبية مع البحث والتصفية.
- فتح ملف قضية وعرض البلاغ والشخصيات والأدلة والخط الزمني.
- تلميحات مع تأكيد خصم النقاط.
- نموذج إجابة وتعليل، ونتيجة تجريبية أولية، وكشف الحل بعد التأكيد.
- حفظ حالة بسيطة في `localStorage` على الجهاز والمتصفح الحالي.

## حدود مهمة قبل الإطلاق
هذه **واجهة نموذجية** وليست منصة إنتاجية مكتملة. حفظ التقدم محلي فقط ولا ينتقل تلقائيًا بين الهاتف واللابتوب. كما أن الحلول والبيانات موجودة في ملفات JavaScript العامة؛ لذلك لا تستخدم هذا النموذج لنشر حلول سرية أو قضايا تنافسية حقيقية. المرحلة التالية هي ربطه بخدمة خلفية وقاعدة بيانات بصلاحيات آمنة، ثم إنشاء لوحة الإدارة والغرف الجماعية.
